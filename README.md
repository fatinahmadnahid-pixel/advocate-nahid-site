# Advocate Abdullah Al Nahid — Portfolio Website

A responsive portfolio website for Advocate Abdullah Al Nahid, practicing at the District & Sessions Judge Court in Dhaka, Bangladesh.

🔗 **Live website:** [https://advnahid.vercel.app/](https://advnahid.vercel.app/)

## Overview

The website presents Advocate Nahid’s professional profile, legal practice areas, qualifications, experience, testimonials, and contact options in one place.

## Features

- Responsive layout for desktop and mobile
- Day and night theme toggle
- Practice areas covering criminal, civil, family, and property law
- Profile, qualifications, and career timeline
- Client testimonials
- Contact links for phone, WhatsApp, email, and LinkedIn
- Contact form that prepares a message to send through WhatsApp
- Scroll animations and mobile navigation

## Built With

- HTML
- CSS
- Vanilla JavaScript
